# Support

Tezuri is pre-release software maintained in public.

- Use [GitHub Discussions](https://github.com/sylin-org/tezuri/discussions) for usage questions and
  design conversation when Discussions is enabled.
- Use [GitHub Issues](https://github.com/sylin-org/tezuri/issues) for reproducible defects and
  bounded feature proposals.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities or reports that contain sensitive details.

Please do not publish credentials, private drafts, repository contents, or security-sensitive logs.
Support is best-effort; no response-time or compatibility SLA is offered.
